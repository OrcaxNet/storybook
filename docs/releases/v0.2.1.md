# Storybook v0.2.1

修复第三方 LLM 已连通，但 `book init` 报 `SB_MODEL_GENERATION_FAILED: generation 未返回有效文本` 的问题。

- 生成探测不再限制为 32 token；先使用 256 token，若服务明确返回因输出上限截断的空正文，再以 4096 token 重试一次。
- OpenAI、Anthropic 和 Ollama 使用相同的有界重试规则，生成请求超时放宽至 30 秒；鉴权错误、无效响应不会重复请求。
- 持续截断时返回 `SB_MODEL_GENERATION_TRUNCATED`，区分输出预算不足与协议响应无效。
- 初始化失败明确提示本次配置尚未保存；`book doctor` 标明默认配置或实际文件路径，并说明 LLM 项不验证生成连通性。
- 在源码仓库运行 `sh ./install.sh` 默认构建并安装本地代码，包含未提交修改，无需等待 Release；支持 `--source <目录>`，原子切换与失败回滚保持一致。
- 在线安装使用一行 `curl -fsSL https://raw.githubusercontent.com/OrcaxNet/storybook/main/install.sh | sh`；脚本自动校验发布包。

从 v0.2.0 升级后重新运行 `book init`，或使用 `book init --config model-config.json` 导入配置。
本地 Ollama 无需密钥时，在向导的 Embedding secret 输入 `-`；直接回车会继承 LLM 密钥。
