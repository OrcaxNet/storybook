## 环境

- Apple M4 / 16 GB；macOS 26.6.2。
- Python 3.14.6 / SQLite 3.54.1；SDK 0.2.179 / MCP 1.30.0，依赖见 uv.lock。
- 系统 Claude CLI 2.1.319；新的隔离合成会话，无工具、safe-mode、独立目录。
- 未采集既有个人或公司业务会话，未配置远程模型端点或常驻生产服务。

## 已取得的证据

| 验证 | 结果与边界 |
| --- | --- |
| 单元/集成测试 | 15 项通过，包含真实 MCP stdio 初始化、工具列表、调用和在线吊销；HTTP/SQLite 非 mock |
| 数据提交故障 | 独立子进程在提交前退出不留下事件，提交后退出保留已确认内容 |
| 长消息 | 规范化 UTF-8 分页可还原 >6000 字符消息；中段关键词可召回；错误字节边界/散列被拒绝 |
| 跨项目权限 | 禁止另一项目读取和跨项目来源合并；读凭据不可写，吊销后不能继续读 |
| 更正/撤权 | 当前摘要和原片段同步拦截；共享来源派生项失效；过期 proposal / 重复导入不能复活撤回项 |
| 结论权威 | 未确认提议从不出现在当前记忆条目；原文候选显式标为 uninterpreted_source |
| 原生只读链路 | 通过 SDK 读取 CLI 实际写入的 8500 字节用户消息，5 个问题均召回并展开全文；前后来源快照一致；重复导入 added=0 |
| 更正闭环实测 | 对上述来源创建/确认测试记忆后撤回，第一次查询即不再返回旧内容 |
| 备份 | Online Backup API 快照通过 integrity_check；撤回状态在快照与重新打开主库后保留 |

原生会话是新生成的公开合成语料，其关键信息位于约 8000 字符填充的中段：日志 `/var/log/pilot-gateway.log`、30 秒超时、429 退避 1/2/4 秒、回滚 `pilot-v1`、明确否决关闭证书校验。5 个问题逐项回读支持片段。

**原生模型请求在 90 秒后超时，未取得助手响应。** 已验证的是 CLI 已持久化用户消息的只读访问，不能声称多轮助手历史、实时观察、模型质量或网络恢复已通过。SDK 的记录覆盖明确为 visible chain，隐藏推理和非文本内容不采集。

## 合成性能基线

`scripts/benchmark.py`：10,000 条可见消息、一个会话、并发 2、100 次精确错误码查询和 100 次原文读取；无模型调用。

- context p50：0.545 ms；p95：0.786 ms。
- evidence p95：6.112 ms。
- 首次查询：0.911 ms；它不是冷磁盘/冷进程测试。
- 错误：0；进程峰值 RSS 约 102.6 MiB（Mac ru_maxrss=107577344 bytes，包含合成装载和测试客户端）。

这些数值只是该合成负载的测量，不表示自然语言相关性、中文改述质量或真实多会话吞吐已达标。独立 40+10 人工标注题尚未建立，不报告 Recall@5 / nDCG 或“普遍零误用”。

## 评审与 QA 的重点

1. 验证原生多轮、工具结果、分支、文件变化及大于 10 MiB 来源的覆盖报告。当前仅显式会话快照，增量 daemon 后续实现。
2. 用独立题目检验中文分词与无结果误报。原型是字词候选检索，不把候选文本解释成权威任务约束。
3. 评估保守的消息块失效粒度；当前优先阻断错误来源，可能隐藏共享块中的有效信息。
4. 生产前补齐配额/保留/删除、备份与撤销日志恢复、持续负载和系统登录生命周期。模板与操作说明不能代替安装与演练。
5. 当前没有自动模型整理任务；过期 revision 门禁已具备并测试，但未来模型 worker 必须实际使用它，不能据本 PR 声称已验证模型任务乱序。
